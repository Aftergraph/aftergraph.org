Research without maturity theatre

Evidence has a state. Marketing does not get to change it.

Aftergraph separates research results, proposed contracts, runtime implementations, and independently checkable production behavior. Visibility never upgrades evidence.

Research result
MISSION-Bench and the intelligence-systems research program publish bounded empirical findings, assumptions and limitations as research, not runtime guarantees.
Specification / standard proposal
SPEC-001 Mission Contract formalizes mission, state, capability, authority, budget, trajectory, evidence and verifier boundaries for evaluation and implementation.
Implementation / runtime
WORKS Execution, Trust Gateway and related repositories implement operational slices with their own maturity and release evidence.
Verified production behavior
Production claims are surfaced only when they have independent runtime evidence. The public site exposes its own deployment health at /healthz; research results do not inherit that status.

Research evidence can justify a promotion decision; it is never runtime authority by itself.

Why Aftergraph

Control the system around the model.

Useful autonomy depends on explicit boundaries, recovery, evidence and economic measurement. The model may reason. The system still has to answer for what happened.

Complete != Verified

An agent declaring completion moves work toward verification. It does not grant itself a verified outcome.

Purpose-bound authority

Delegated permissions are scoped, attenuated, time-bounded and revocable instead of ambient.

Durable execution and recovery

Authoritative mission state survives model turns and supports controlled recovery after failures or interruption.

Deterministic evidence gates

Verification is grounded in evidence and external criteria rather than another confident completion message.

Cost per verified outcome

System economics are measured against useful verified results, including the overhead of control and recovery.

Open repositories

Inspect implementation, releases, tests and history directly in GitHub.

Provenance-aware docs

The Knowledge Plane pins source state and renders provenance rather than silently owning truth.

Fail-closed boundaries

Authority, budgets, verification and evidence remain separate concerns instead of one omnipotent agent loop.
