Why it matters

Agents got real access. Trust didn't.

Most agent work today rests on the agent's own report. That is fine for a demo and dangerous for production.

01

"Done" is a claim

An agent saying tests passed isn't the same as tests passing on the code that shipped.

02

Access never ends

Keys outlive the task. Nobody can say what the agent was allowed to do, or for how long.

03

Long work breaks

A crash halfway through a two-day job means starting over, or half a change in production.
