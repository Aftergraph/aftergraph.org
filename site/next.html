The problem

Agents are getting real access. Trust hasn't caught up.

Coding agents open PRs, ops agents touch production, research agents run for days. Today most of that rests on the agent's own report.

01

"Done" is a claim

An agent saying tests pass isn't the same as tests passing on the code that shipped.

02

Access is all or nothing

API keys don't expire with the task. Nobody can say what the agent was allowed to do, and for how long.

03

Long work falls over

A crash halfway through a two-day job means starting over, or worse, half a change in production.

How Aftergraph works

Four planes between an intent and a verified result.

Each plane is its own system with its own contract, so no single component, including the agent, has to be trusted.

Authority

AIE

Scoped, budgeted, expiring permission for every task, and revocation that actually stops work.

Enforcement

Trust Gateway

Fail-closed admission. Actions outside the grant are refused before they happen, with a reason.
