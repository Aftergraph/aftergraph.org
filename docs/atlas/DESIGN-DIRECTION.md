# Atlas Design Direction v1 (owner-set 2026-09-09)

Reading: operational observatory for technical owners, in an
instrument-cartography language. Dials: ENERGY 3 / RHYTHM 3 / MOTION 1.
antislop applies DURING (Delivery Gate before every commit).

Identity motif: the evidence trace (source → assertion → evidence →
verified). It recurs: landing hero, graph edges, section dividers.
One focal point per screen: the living system map. Everything defers.

Antislop hard rules for this redesign: no em dash anywhere; no fake
numbers without projection source; every button does something; empty /
loading / error states ship with every view; keyboard + focus visible;
contrast AA; mobile holds; build + DOM gates stay green.

What changes: composition and hierarchy first (what the eye meets,
what dominates, what whispers). Technique needs a written one-line
reason (R-31). What stays: truth-plane semantics, provenance copy,
all gates, Brand OS tokens.
